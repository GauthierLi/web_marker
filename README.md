# 🖼️ 图片展示系统

一个功能丰富的前后端分离图片展示系统，支持批量选择、路径导出、快捷键操作等功能。

## ✨ 功能特性

### 📂 输入支持
- **txt文件路径**：每行一个图片路径/URL
- **图片文件夹路径**：自动递归扫描所有图片

### 🖱️ 选择操作
- **左键点击**：选择/取消选择图片
- **F键**：全选/反选当前可见图片
- **Ctrl+鼠标滑动**：快速批量选择
- **全选按钮**：一键操作所有可见图片

### 🔍 图片查看
- **右键放大**：直接放大查看图片
- **导航切换**：J/K键或←/→键切换图片
- **选择状态**：放大模式显示选择状态
- **F键/空格键**：在放大模式下选择当前图片

### 📋 路径管理
- **路径复制**：点击路径文本复制到剪贴板
- **路径导出**：导出选中图片路径为txt文件
- **路径导入**：导入之前导出的txt文件，自动勾选对应图片
- **浮动提示**：路径悬停显示操作提示

### 🎨 界面特性
- **响应式设计**：自适应不同屏幕尺寸
- **浮动面板**：滚动时显示选择状态面板
- **动画效果**：流畅的过渡和反馈动画
- **状态同步**：选择状态实时同步显示

### 📊 特征可视化 (NEW!)
- **智能特征提取**：自动提取图片的视觉特征
- **PCA降维**：使用主成分分析将特征降维到3D空间
- **t-SNE降维**：使用t-SNE算法进行非线性降维可视化
- **交互式3D图表**：可旋转、缩放的3D散点图
- **选择状态可视化**：选中图片显示为绿色点，未选中为灰色点
- **悬停信息**：鼠标悬停显示图片索引和坐标信息
- **🖼️ 缩略图预览**：右键点击特征点显示对应图片的缩略图
- **⚡ 智能缓存**：首次计算后自动缓存特征数据，后续选择更新仅改变颜色，无需重新计算
- **缓存管理**：支持手动清除缓存，自动检测图片集或方法变化时清空缓存

## 🚀 快速启动

### 方法1：使用启动脚本（推荐）

```bash
./quick_start.sh
```

### 方法2：手动启动

1. **安装依赖**
```bash
pip3 install fastapi uvicorn python-multipart
```

2. **启动后端**
```bash
python3 backend.py
```

3. **访问前端**
在浏览器中打开：`http://localhost:8001/frontend_enhanced.html`

## 📖 使用说明

### 1. 加载图片
- 在输入框中输入txt文件路径或图片文件夹路径
- 点击"🚀 加载图片"按钮
- 等待图片加载完成

### 2. 选择图片
- **单选**：左键点击图片
- **批量选择**：按住Ctrl键，鼠标滑过图片
- **可见全选**：按F键或点击全选按钮
- **放大选择**：右键放大后，按F键或空格键

### 3. 导出和导入路径
- **导出**：选择完图片后，点击"📥 导出路径"按钮，自动下载包含所选图片路径的txt文件
- **导入**：点击"📁 导入已选择"按钮，选择之前导出的txt文件，系统会自动勾选文件中包含的图片路径

### 4. 图片查看
- **放大查看**：右键点击图片
- **切换图片**：按J/K键或←/→键
- **关闭放大**：按ESC键或点击关闭按钮

### 5. 特征可视化 ⭐
- **步骤1**：选择一些图片（建议选择10-200张）
- **步骤2**：点击"🎨 特征可视化"按钮
- **步骤3**：选择降维方法（PCA或t-SNE）
- **步骤4**：点击"🚀 生成可视化"，等待计算完成
- **后续使用**：
  - 更改选择的图片 → 点击"🚀 生成可视化"即可快速更新（使用缓存）
  - 更改降维方法 → 需要重新计算特征
  - 手动清缓存 → 点击"🗑️ 清除缓存"按钮

**性能提示**：
- PCA适合大数据集（>200张图片），计算速度快
- t-SNE适合小数据集（≤200张图片），可视化效果更好
- 首次计算会提取特征并降维，耗时较长；后续仅更新颜色，速度很快

## ⌨️ 快捷键

### 正常模式
- `M` - 全选/反选当前可见图片
- `Ctrl+鼠标` - 快速批量选择
- `右键` - 放大图片

### 放大模式
- `J` / `→` - 下一张图片
- `K` / `←` - 上一张图片
- `M` / `空格` - 选择/反选当前图片
- `ESC` - 关闭放大模式

## 🔧 技术架构

### 后端
- **FastAPI**：现代化的Python Web框架
- **Uvicorn**：ASGI服务器
- **PIL/Pillow**：图片处理和特征提取
- **scikit-learn**：机器学习库（PCA/t-SNE降维）
- **静态文件服务**：支持本地图片访问

### 前端
- **原生JavaScript**：无框架依赖，智能缓存机制
- **Plotly.js**：3D可视化图表库
- **CSS3动画**：流畅的用户界面
- **响应式设计**：适配各种设备

## 🌐 API接口

### GET /get_images
获取图片列表

**参数：**
- `txt_path`: txt文件路径或图片文件夹路径

**返回：**
```json
{
    "images": ["图片URL列表"],
    "count": 图片数量,
    "type": "file|directory"
}
```

### GET /file
文件服务接口

**参数：**
- `path`: 文件路径

## 🔍 故障排除

### 端口被占用
```bash
# 查找占用端口的进程
netstat -tlnp | grep :8001

# 终止进程
kill -9 <PID>
```

### 依赖安装失败
```bash
# 更新pip
pip3 install --upgrade pip

# 重新安装依赖
pip3 install --force-reinstall fastapi uvicorn
```

### 图片加载失败
- 检查文件路径是否正确
- 确认图片文件存在且格式支持
- 检查网络连接（对于在线图片）
